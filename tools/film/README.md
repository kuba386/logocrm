# Ролик «LogoCRM за минуту»

`film.html` — 60-секундная моушн-графика для лендинга (`apps/web/public/video/logocrm-60s.mp4`).
Весь кадр — функция времени `renderAt(t)`, поэтому рендер покадровый и без рывков.
Сцены и тайминги — массив `SCENES` и блоки `// 1. … // 8.` в скрипте.

Предпросмотр в реальном времени: открыть `film.html?play` в Chrome (шрифты подставятся
только при рендере — в предпросмотре будет системный).

Пересобрать после правки текста:

```bash
cd tools/film && npm i --workspaces=false && node render.cjs
```

Рендер идёт в установленном Chrome (WebCodecs, H.264 High, 1280×720, ~1 Мбит/с), около
двух минут; результат и постер (кадр 9,7 с) кладутся прямо в `apps/web/public/video`.
Держите файл до ~8 МБ: он лежит в репозитории и грузится на телефоне по нажатию.
