## Что уже построено без макетов

Этапы 0–3 сделаны до появления этого каталога, и перевод на новые токены
будет ретрофитом, а не подгонкой пустого проекта. Масштаб на 10 сентября
2026 года, до ретрофита:

- **17 экранов**: `/login`, `/onboarding`, `/select-center`, `/invite/[token]`,
  `/access-revoked`, `/app`, `/app/schedule`, `/app/students`,
  `/app/students/[id]`, `/app/payers`, `/app/payers/[id]`, `/app/groups`,
  `/app/settings/staff`, `/app/settings/rooms`, `/app/settings/services`,
  `/error`, `/`;
- **9 компонентов** в `apps/web/components/ui`: alert, button, card,
  catalog-form, dialog, input, label, select, table.

Токены в `globals.css`/`tailwind.config.ts` уже обновлены на Material 3
(DESIGN.md, 2026-09-10) — 17 существующих страниц читают переменные
и автоматически подхватят новую тему без правки JSX, но их собственная
вёрстка (плотность, структура) ещё не пересобрана под новые макеты — это
и есть ретрофит, отдельная волна работы, не сделанная в этот проход.

Четыре из пяти семантических цветов статуса посещаемости уже в токенах
(`--status-success/warning/danger/neutral`) — вытащены из бейджей на макетах.
Пятого, «Болел», среди присланных экранов не было ни разу; голубой оттенок,
нужный по CLAUDE.md для отличия при дальтонизме, ещё предстоит сгенерировать.

## Как генерировать

Stitch подключается как MCP-сервер скриптом `bash ~/add-stitch.sh`: ключ
вводится скрыто, хранит его Claude Code в `~/.claude.json` — никогда в
репозитории. `.mcp.json` здесь не заводится по той же причине.

После подключения сессию нужно перезапустить — новый MCP-сервер подхватывается
при старте.

Бриф на дизайн-систему и шесть экранов этапа 4 — [stage-4-brief.md](stage-4-brief.md).
С него начинается первая сессия с инструментами Stitch.

Лимит около 350 генераций в месяц на аккаунт. Правится конкретный экран, а не
весь проект: перегенерация всего ради одной подписи съедает лимит впустую.
