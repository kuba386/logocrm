# DESIGN.md — дизайн-система LogoCRM

Источник: генерация в Stitch, 2026-09-10. Канонический стиль выбран
владельцем среди двух, вернувшихся в одной партии, — стиль по умолчанию
Material 3, в котором Stitch отдал 11 из 13 экранов. Второй стиль (тёплый
бирюзовый, `#0F766E`, Inter-иконки) пришёл только на двух экранах — «Вход» и
«Протокол занятия» — и не принят: эти два экрана нужно перегенерировать в
каноническом стиле, см. «Пробелы» внизу файла. Правила переноса —
[ADR-007](../Decisions/ADR-007-design-source.md): токены переносятся в код
вручную, HTML из Stitch не копируется.

## Цвет

Stitch отдал полную ролевую палитру Material 3 (47 ролей). Ниже — свод к
двенадцати переменным shadcn, которые уже читают `components/ui/*`, плюс
статусные цвета, вытащенные из бейджей на самих экранах (не из Material-ролей
— Stitch использовал для статусов отдельные произвольные HEX прямо в разметке,
одинаковые на всех экранах, что и делает их системой, а не совпадением).

| shadcn-переменная | Material 3 роль | HEX | Использование в макетах |
|---|---|---|---|
| `--background` | `background` | `#fff8f5` | Фон страницы, тёплый почти белый |
| `--foreground` | `on-background` | `#1e1b19` | Основной текст |
| `--card` | `surface-container-lowest` | `#ffffff` | Карточки, панели, шапка, сайдбар |
| `--card-foreground` | `on-surface` | `#1e1b19` | Текст на карточках |
| `--primary` | `primary-container` | `#0f766e` | Заливка основных кнопок, сегодняшняя дата в календаре |
| `--primary-foreground` | `on-primary` | `#ffffff` | Текст на основных кнопках |
| `--secondary` | `secondary-container` | `#bdece2` | Активный пункт меню, светлые чипы |
| `--secondary-foreground` | `on-secondary-container` | `#416c65` | Текст на активном пункте меню |
| `--muted` / `--accent` | `surface-container-low` | `#faf2ee` | Зебра таблиц, hover-фон |
| `--muted-foreground` | `on-surface-variant` | `#3e4947` | Вторичный текст, подписи |
| `--destructive` | `error` | `#ba1a1a` | Опасные действия, ошибки |
| `--border` / `--input` | `outline-variant` | `#bdc9c6` | Разделители, обводка полей |
| `--radius` | — | `0.5rem` | Совпадает с `rounded-xl` у Stitch — карточки и кнопки |

Наведение на основную кнопку в макетах на тон темнее заливки —
`primary` (M3-роль, не `primary-container`) `#005c55`; используется как
`--ring` и как более тёмный оттенок primary для `hover:`, отдельной
переменной под него не заводили — компоненты shadcn умеют `hover:bg-primary/90`
без нового токена.

### Статусы (бейджи, не Material-роли)

Все экраны used одну и ту же пару «насыщенный текст / бледная плашка» для
одних и тех же четырёх смыслов — это уже система, не случайность:

| Токен | Текст/иконка | Фон плашки | Смысл в макетах |
|---|---|---|---|
| `--status-success` | `#15803D` | `#DCFCE7` | Проведено, оплачен, активен |
| `--status-warning` | `#B45309` | `#FEF3C7` | Заканчивается абонемент, требуется продление |
| `--status-danger` | `#B91C1C` | `#FEE2E2` | Отменено, долг |
| `--status-neutral` | `#64748B` | `#F1F5F9` | Запланировано, на паузе |

Этих четырёх **не хватает** на пятый смысл — «Болел» — CLAUDE.md-требование
неотличимости при дальтонизме просило голубой ни один экран не сдал; см.
«Пробелы».

## Типографика

Один гротеск — Inter, с фолбэком `system-ui, sans-serif` (в макетах фолбэка
нет, добавлен при переносе). Шкала полностью своя, не дефолтный Tailwind:

| Класс | Размер / высота строки | Трекинг | Вес | Где |
|---|---|---|---|---|
| `headline-lg` | 24px / 36px | -0.015em | 600 | Заголовок страницы (`<h1>`) |
| `headline-md` | 20px / 30px | -0.01em | 600 | Заголовок диалога |
| `headline-sm` | 16px / 24px | -0.005em | 600 | Заголовок секции/карточки |
| `body-md-medium` | 14px / 21px | 0em | 500 | Акцентный текст в строке (имя ученика в таблице) |
| `body-md` | 14px / 21px | 0em | 400 | Основной текст |
| `body-sm` | 12px / 18px | 0.01em | 400 | Вторичный текст, подписи под строкой |
| `label-sm` | 12px / 18px | 0.015em | 500 | Подписи полей, заголовки колонок |
| `label-xs` | 11px / 16px | 0.02em | 600 | Мелкие бейджи, метки времени |

## Плотность и отступы

Шкала отступов кратна 4px, с именованными шагами для частых значений —
`space-4` … `space-40`. Плюс два макетных размера с собственными именами:
`sidebar-width: 240px`, `sidebar-collapsed: 64px`, `modal-max-width: 540px`.
Радиус: `DEFAULT 0.125rem`, `lg 0.25rem`, `xl 0.5rem` (это и есть `--radius`
проекта), `full 0.75rem`.

**Важно:** ключ `full: 0.75rem` в Stitch-конфиге переопределяет дефолтный
Tailwind `rounded-full` (обычно 9999px, настоящий круг). В макетах это не
мешало, потому что круглые аватарки и иконки там квадратные `w-N h-N` с
явным намерением быть кругом. Если скопировать ключ `full` в
`tailwind.config.ts` как есть, все существующие `rounded-full` — аватарки
специалистов, круглые бейджи с инициалами — перестанут быть кругами. Ключ
**не перенесён**.

Плотность отличается по ролям, как и требовало ТЗ: таблица администратора —
строка `h-12`/`h-14` (48–56px), тач-цели на мобильных экранах — не меньше
`min-h-[44px]` (кнопки нижней навигации, свайп-карточки).

## Компоненты, подтверждённые макетами

Кнопки (основная заливка / контурная / призрачная / деструктивная), поле
с подписью сверху, селект, диалог по центру с `modal-max-width`, боковая
панель `w-[400px]` (занятие), нижняя шторка на мобильном (сортировка,
подтверждение отмены), таблица с зеброй и hover-строкой, бейдж-плашка,
карточка `rounded-xl shadow-sm`, пустое состояние (иконка + строка + два
CTA), сегментированный переключатель (Неделя/День, тип отсутствия).
Реализация — на существующих `components/ui/*`, а не на вставке разметки
Stitch, см. ADR-007.

## Пробелы — экраны и цвета, которых ещё нет

Записано, чтобы не потерять при следующей генерации в Stitch:

1. **Два экрана в непринятом стиле** — `Вход` и `Протокол занятия` — нужно
   перегенерировать в Material 3, том же, что и остальные 11. Промт для
   регенерации не должен включать «базовый промт» из старого внутреннего
   плана (тёплый бирюзовый `#0F766E`, Inter-иконки) — именно он и разошёлся
   со стилем остальных экранов.
2. **Пятый статус-цвет** — «Болел»: нужен голубой (`sky`), отличимый от
   зелёного/янтарного/красного при дальтонизме, желательно с иконкой или
   буквой поверх цвета, а не только оттенком — требование CLAUDE.md, ни один
   присланный экран его не покрыл.
3. **Экран `debts`** (`/app/debts`, долги и нулевые остатки) — не пришёл ни
   в одной из партий; ближе всего «Ученики — список» с фильтром «С долгом»,
   но выделенного экрана нет.
4. **Экран настроек** статусов посещения и типов абонементов
   (`/app/settings/attendance-statuses`, `/app/settings/subscription-types`)
   — не пришёл; «Справочники и настройки студии» покрывает услуги, кабинеты
   и абонементы, но не статусы посещения.
5. **Компактная панель отметки посещения** — экран, подписанный в присланной
   партии «Отметка занятия (мобильный)», на деле оказался расписанием дня
   специалиста с одной кнопкой «Быстрая отметка», а не самой панелью
   отметки со списком учеников и цветными статусами. «Протокол занятия»
   ближе по смыслу (список блоков + посещение), но избыточен для быстрой
   отметки между занятиями и в непринятом стиле — см. пункт 1.

Полный список экранов из этой партии и куда они легли — таблица в
[README.md](README.md).
