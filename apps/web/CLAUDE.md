# apps/web — правила фронтенда

Общие правила — корневой `CLAUDE.md`.

- **Ошибки разбираются в одном месте** — `apps/web/lib/errors.ts`. Компоненты
  не парсят ошибки у себя: иначе один конфликт покажется тремя текстами, а
  новый вызов забудут обработать.
- **Оптимистичного UI нет.** Только ответ сервера. Иначе при отказе запись
  появится и исчезнет — на общем экране это читается как баг базы.
- **Время рендерится в часовом поясе центра**, не браузера:
  `centers.settings->>'timezone'`, дефолт `Asia/Bishkek`. Администратор из
  поездки должен видеть расписание студии.
- Одна страница на все роли, ветвление внутри. Отдельные страницы под
  admin/teacher/parent разъедутся через два этапа.
- Список за период — один запрос на диапазон, не N запросов по дням.
